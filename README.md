# teste

Exportado pelo Navegador 3D em 2026-09-16.

- `teste.glb`: o modelo completo (abre em qualquer visualizador glTF).
- `projeto.json`: câmera, grade e configuração de AR.
- `preview.png`: captura da cena.
- `ar/`: realidade aumentada. Imprima `ar/marcador.png` (a moldura preta inteira, com a margem branca),
  publique esta pasta em um site HTTPS (GitHub Pages serve) e abra `ar/index.html` no celular
  apontando a câmera para o marcador impresso. Tamanho na AR: 1
  (1 = o modelo aparece do tamanho do marcador).

A câmera só funciona em HTTPS e fora de navegadores embutidos: se abrir pelo Instagram ou WhatsApp,
toque em "Abrir no navegador".

Convenção: Y para cima, metros.
